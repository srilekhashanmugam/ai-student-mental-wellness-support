# AI-Powered Student Mental Wellness Support Assistant

MindEase is a web-based student wellness support prototype designed to help students check in with their mood, explore simple wellness activities, and reflect through a private journal.

## Features

- Mood check-in
- Stress level assessment
- Personalized wellness suggestions
- 60-second breathing exercise
- 5-4-3-2-1 grounding exercise
- Reflection prompts
- Private journal
- Local browser storage
- Responsive web interface
- Student-focused wellness support

## How It Works

1. Select your current mood.
2. Choose your stress level.
3. Get a supportive suggestion based on your selection.
4. Use the available wellness tools.
5. Write and save a personal journal entry.

## AI-Style Support

The current version uses a lightweight rule-based recommendation approach.

It considers:
- Selected mood
- Reported stress level
- Wellness activity preferences

The current prototype is not a medical or diagnostic system.

## Run Locally

Clone or download the repository and open the project using a local server.

```bash
cd ai-student-mental-wellness-support
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Privacy

Journal information is stored locally in the user's browser for this prototype. No external database is currently used.

## Safety Notice

MindEase is a student wellness support prototype and should not be used for medical diagnosis or treatment. Students experiencing significant difficulties should consider speaking with a trusted person, campus counselor, or qualified mental health professional.
